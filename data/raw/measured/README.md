# Measured Raw Data

Direktori ini dicadangkan untuk penyimpanan data pengukuran channel probing fisik (empirical measurements).

Catatan metodologis:
- Channel probing saat ini ditunda (*postponed*), bukan digantikan (*not replaced*).
- Ketika pengukuran channel fisik dilakukan, data mentah dari transceiver Alice, Bob, dan Eve akan disimpan di sini.
